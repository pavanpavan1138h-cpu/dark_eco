# Phase 4 Notebooks: Food Webs & Species Traits (`notebooks/phase_4_foodweb_traits/`)

This directory will contain the notebooks for **Phase 4: Trophic Interaction Networks, Functional Traits, and Nocturnality Encoding**.

## Planned Workflows (Phase 4)

- **`01_foodweb_source_investigation.ipynb`**: Review of GloBI interaction types, Mangal topologies, and South-Indian ecological literature.
- **`02_interaction_data_collection.ipynb`**: Querying GloBI for confirmed predator-prey, herbivore-plant, and plant-pollinator interactions among regional taxa.
- **`03_species_trait_collection.ipynb`**: Joining species functional traits from EltonTraits 1.0 (nocturnality, foraging stratum), AVONET (hand-wing index, trophic niche), and PanTHERIA (activity cycle).
- **`04_data_inspection_quality.ipynb`**: Auditing taxonomic synonym matching and imputing missing trait values via phylogenetic nearest-neighbour averages.
- **`05_species_matching_preprocessing.ipynb`**: Constructing directed regional food-web graphs and node feature matrices for graph neural network modelling.

*Note: Phase 4 will begin only after Phase 3 approval.*
