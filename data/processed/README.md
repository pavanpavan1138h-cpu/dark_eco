# Processed Data Archive (`data/processed/`)

This directory contains **standardized, cleaned, and gridded research datasets** generated by the project's analytical notebooks.

## Contents & Conventions
- Every processed file is mapped to the common **5 km × 5 km regular grid** (`BLR_Rxx_Cxx`, `MYS_Rxx_Cxx`, `NB_Rxx_Cxx`) in UTM Zone 43N (`EPSG:32643`) or WGS 84 (`EPSG:4326`).
- Every transformation must be 100% reproducible by running the corresponding notebook from `notebooks/`.
- Meaningful, standardized naming conventions are strictly enforced (e.g., `{phase}_{dataset}_{region}_{frequency}.csv` or `.parquet`). No vague names like `final_final2.csv` are permitted.
- Large research arrays generated here are excluded from Git via `.gitignore`.
