# External References (`data/external_references/`)

This directory is reserved for non-tabular, external reference materials such as:
- Government gazette notifications and master plans (BBMP 2031 Master Plan, MUDA Master Plan, NTCA tiger reserve boundary notifications).
- Data user guides and sensor calibration handbooks (DMSP-OLS calibration manuals, VIIRS-DNB user guides).
- Published survey PDF reports (e.g. WII All India Tiger Estimation Technical Reports).

## Rules
- Binary PDFs and large reports stored here are excluded from Git via `.gitignore`.
- Every external document deposited here must be logged in a manifest describing its title, authoring agency, publication year, and source URL.
