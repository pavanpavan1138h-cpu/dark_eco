# Reports Directory (`reports/`)

This directory contains analytical completion reports, spatial and temporal framework documents, figures, and data quality audits organized by phase.

## Subdirectories

- **`phase_1/`**:
  - `phase_1_completion_report.md`: Milestone completion report for Phase 1.
  - `geographical_framework.md`: In-depth report on study areas, boundary justifications, and UTM 43N grid design.
  - `temporal_coverage_report.md`: Sensor transition analysis (DMSP to VIIRS), observer effort trends, and two-tiered temporal architecture.
  - `figures/`: High-resolution figures and maps generated during Phase 1 notebook execution:
    - `study_windows_overview.png`: Relative positions of the three study windows.
    - `study_windows_with_osm_reference.png`: Maps of the three windows with 5 km grid cells and OSM reference boundaries.
    - `dataset_temporal_coverage.png`: Timeline chart of candidate datasets against the 1992–2024 target.
    - `gbif_temporal_surge_by_region.png`: Logarithmic plot of annual biodiversity occurrence growth across the three landscapes.
- **`phase_2/`**, **`phase_3/`**, **`phase_4/`**, **`phase_5/`**: Destination directories for subsequent phase milestone reports.
- **`data_quality/`**: Cross-phase quality assurance reports, missing-value audits, and sensor discontinuity evaluations.
